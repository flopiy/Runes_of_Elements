# Руни Стихій — Runes of Elements

Кооперативна покрокова карткова гра, створена в Unity.
Команда з чотирьох магів проходить башту, комбінує руни
для заклинань і бореться з монстрами та босом.

## Технології

- Unity 6000.3.10f1
- Universal Render Pipeline (URP)
- New Input System
- UI Toolkit
- C#
- Unity Netcode та Unity Services — мережевий шар

Цільова платформа: Windows x64.

## Ігровий процес

### Кампанія

Башта складається з 10 поверхів, по 3 хвилі на кожному.
На останньому поверсі команда зустрічає боса.

- Між хвилями живі маги відновлюють 3 HP.
- Після завершення поверху живі маги отримують руну та 3 HP.
- Маги, які вибули, повертаються після поверху з 3 HP.
- Якщо всі маги вибули — команда програє.

### Маги

| Маг | Здібність |
| --- | --- |
| Піромант | Вогняні заклинання коштують на 1 концентрацію менше |
| Гідромант | Після водного заклинання отримує щит від наступної атаки монстра |
| Електромант | На результаті 6 блискавка завдає додаткові 3 шкоди іншому монстру |
| Кріомант | Раз за хвилю може заморозити монстра |

### Руни та заклинання

Заклинання складається з однієї Стихії та однієї Форми.

<b>Стихії:</b> Вогонь, Вода, Лід, Блискавка.

<b>Форми:</b>

- Промінь — вражає ціль та монстра в тій самій колонці іншого ряду.
- Сфера — вражає ціль та сусідніх монстрів у її ряду.

Шкода визначається кидком d6.
Вогняні заклинання мають додаткові +2 базової шкоди.

Якщо ввімкнений Стихійний перегрів, результат 6 накладає
додатковий ефект залежно від стихії.

### Хід і концентрація

- Максимум концентрації — 5.
- На старті хвилі маг зазвичай має 4 концентрації.
- На початку ходу отримує 1 концентрацію.
- Після медитації наступного ходу отримує 2 замість 1.
- Перед основною дією можна замінити одну руну.
- Основна дія — заклинання, медитація або завершення ходу.
- Крижаний полон можна застосувати перед основною дією.

Після ходів магів атакують монстри, потім відбувається
відновлення: живі маги зазвичай отримують 5 HP.

### Карти та стани

У грі є 20 карт трьох категорій:

- Благословення;
- Прокляття;
- Ризик.

Карти змінюють вартість заклинань, шкоду, лікування,
ліміт руки та інші правила.

Стани включають Опік, Отруту, Замороження, Приголомшення,
Щит, Ослаблення, Мовчання та інші ефекти.

### Боти та режими

- Соло з ботами.
- Локальна гра кількох людей за одним комп’ютером — hot-seat.
- Реалізовано сервер-авторитетний мережевий шар.

Для онлайн-гри потрібні відповідні налаштування Unity Services.

## Запуск проєкту

1. Клонуйте репозиторій.
2. У Unity Hub натисніть <b>Add → Add project from disk</b>.
3. Виберіть кореневу папку проєкту.
4. Відкрийте проєкт у Unity <b>6000.3.10f1</b>.
5. Дочекайтеся імпорту ресурсів і встановлення пакетів.
6. Відкрийте сцену:
   `Assets/Scenes/RoE_MainMenu.unity`
7. Натисніть <b>Play</b> і виберіть режим гри.

| Папка / файл | Призначення |
| --- | --- |
| `Core/RulesEngine.cs` | Правила, ходи, атаки, шкода та кампанія |

| `Core/Commands.cs` | Команди гравця |

| `Presentation/HUD/` | Інтерфейс бою |
| `Presentation/Menu/` | Головне меню |
| `Presentation/Session/` | Локальні сесії, боти та таймер ходу |

| `Editor/` | Генератор даних |
| `Tests/EditMode/` | Тести правил |

## 3D-об’єкти та ефекти

### Blender

Якщо папка експорту включена до репозиторію:

- `BlenderExports/RoE_Tower.blend` — башта;
- `BlenderExports/RoE_Arena.blend` — арена.

Експорти містять геометрію та спрощені матеріали.
Unity-частинки й шейдерні ефекти не переносяться в Blender.

## Тести

Відкрийте <b>Window → General → Test Runner</b>, виберіть
<b>EditMode</b> та натисніть <b>Run All</b>.

Тести перевіряють концентрацію, ходи, геометрію заклинань,
раунди, кампанію, здібності, карти та знімки стану.

## Збірка для Windows

1. Відкрийте <b>File → Build Profiles</b>.
2. Виберіть платформу Windows.
3. Перевірте список сцен: головне меню та арена бою.
4. Зробіть головне меню першою сценою.
5. Натисніть <b>Build</b>.

## Git

До репозиторію потрібно додавати:

- `Assets/` разом із файлами `.meta`;
- `Packages/`;
- `ProjectSettings/`.

Папки `Library`, `Temp`, `Logs`, `Obj` та збірки
не повинні потрапляти до Git.
